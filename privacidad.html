Política de privacidad

Sala de Incidentes YT · Última actualización: 6 de noviembre de 2026

Qué es esta aplicación

Sala de Incidentes YT es una herramienta personal que usa el propietario del canal de YouTube «Sala de Incidentes». Sirve para subir videos propios a ese canal y para consultar las estadísticas de esos videos. No tiene otros usuarios.

Qué datos usa de tu cuenta de Google

Solo con la autorización del propietario de la cuenta, la aplicación accede a:

  • Subir videos (permiso youtube.upload): para publicar los videos y sus miniaturas en el canal.
  • Ver datos del canal (youtube.readonly): para comprobar el estado y las cifras públicas de los videos subidos.
  • Ver informes de YouTube Analytics (yt-analytics.readonly): para consultar vistas, «me gusta», comentarios, veces compartido y tiempo de reproducción de los videos del canal.

Cómo se almacenan y se usan

  • Los datos se guardan únicamente en los equipos personales del propietario, en una base de datos local.
  • Las credenciales de acceso se guardan en un archivo local protegido y no se comparten.
  • No se venden, no se transfieren ni se comparten datos con terceros, y no se usan para publicidad.
  • No se usan para entrenar modelos de inteligencia artificial.

El uso que hace esta aplicación de la información recibida de las API de Google cumple con la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

Puedes retirar el permiso en cualquier momento desde myaccount.google.com/permissions. También puedes borrar los datos locales eliminando el archivo de credenciales y la base de datos.
